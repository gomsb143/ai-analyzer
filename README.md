# 🧠 AI Process & Idea Intelligence Analyzer

An enterprise-grade decision intelligence engine designed to help business leaders determine the optimal path for digital evolution: **Optimize**, **Automate**, or **Transform with AI**.

![Project Status](https://img.shields.io/badge/Status-Live-seagreen)
![Tech Stack](https://img.shields.io/badge/Stack-Next.js%20%7C%20TypeScript%20%7C%20Tailwind-blue)

## 🎯 Overview

This application serves as a strategic consulting tool that analyzes business workflows or AI concepts. It uses deterministic keyword matching logic to provide high-quality recommendations, business impact summaries, and a comprehensive 30-day execution roadmap.

## ✨ Key Features

- **Dual-Mode Analysis**: Specialized logic for analyzing existing **Business Processes** or validating new **AI Ideas**.
- **Strategic Classification**: Automatically categorizes inputs into:
  - 🟢 **Optimize**: Streamlining workflows before applying technology.
  - 🔵 **Workflow Automation**: Using rules-based logic (APIs, RPA) for efficiency.
  - 🟣 **AI Transformation**: Leveraging LLMs and Machine Learning for cognitive tasks.
- **Business Impact Projection**: Estimates time savings, efficiency gains, and cost reductions.
- **30-Day Execution Roadmap**: A week-by-week implementation guide tailored to the recommendation.
- **Premium UI/UX**: A clean, sea-green enterprise aesthetic with smooth animations and responsive design.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) & Vanilla CSS (Custom Tokens)
- **Icons**: Lucide React (Inline SVGs)
- **Deployment**: Optimized for Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR-USERNAME/ai-analyzer.git
   cd ai-analyzer
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open the app**:
   Navigate to [http://localhost:3000](http://localhost:3000) in your browser.

## 🧠 How It Works

The analyzer uses a structured keyword-based engine to classify text:
1. **AI Transform**: Triggered by cognitive terms like *predict, generate, llm, gpt, chatbot*.
2. **Automation**: Triggered by integration terms like *api, sync, webhook, workflow, transfer*.
3. **Optimize**: Default state focused on process streamlining and waste reduction.
